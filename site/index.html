Questions

Good to know.

Is it really free?

Yes. Brickyard is MIT licensed and has no account. You pay your agent providers directly, the same as you do now.

Which agents does it support?

Chat works with Claude, Codex, Gemini, OpenCode and Grok. Cursor, Muse Code and Pi are detected but cannot chat yet.

Does Brickyard see my API keys or code?

No. It starts the agent CLIs already on your PC and reads their output. Threads are stored only on your machine.

Why does Windows warn me when I install it?

The beta installer is not code signed yet, so SmartScreen shows a warning. Choose "More info", then "Run anyway".

Can an agent break my game?

It can, which is why there are access levels. Studio has no undo for agent edits, so save a copy of your place before big changes.

Mac or Linux?

Not yet. The beta is Windows only. The code is open if you want to help.
